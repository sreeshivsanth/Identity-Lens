## ✨ Features

### 🔍 OSINT Discovery Engine
- **Username Enumeration** — Scans 3,000+ platforms using Sherlock, Maigret, and WhatsMyName
- **Breach Monitoring** — Queries HIBP, DeHashed, Snusbase, and LeakCheck databases
- **Data Broker Detection** — Identifies PII listings across 640+ data broker sites
- **Email OSINT** — Discovers accounts registered with target emails via Holehe
- **Phone OSINT** — Analyzes phone number exposure via PhoneInfoga
- **Dark Web Monitoring** — Scans paste sites and dark web indexes via IntelX

### 🧠 Perception AI (NLP Pipeline)
- **Named Entity Recognition (NER)** — Extracts entities using spaCy + GLiNER zero-shot models
- **Entity Disambiguation** — Context-window resolver to distinguish identical names
- **Aspect-Based Sentiment Analysis** — RoBERTa-powered analysis of *what* is being praised/criticized
- **Toxicity & Threat Scoring** — Detects doxxing, harassment, and coordinated attacks via HateBERT
- **Composite Risk Scoring** — Weighted 0-100 Digital Exposure Score

### 🗑️ Automated Remediation
- **Data Broker Opt-Outs** — Headless Playwright automation with CAPTCHA solving
- **DSAR Generation** — Multi-jurisdiction legal request templates (GDPR, CCPA, DPDP, LGPD)
- **Platform Revocation** — OAuth 2.0 + PKCE direct post/media deletion
- **Search Deindexing** — Automated Google/Bing legal removal filings
- **Continuous Re-Monitoring** — Weekly delta scans with regression detection

### 🔐 Zero-Knowledge Privacy
- **Client-Side Encryption** — AES-256-GCM encryption before data leaves the browser
- **Key Derivation** — Argon2id KDF from user password
- **Hash-Only Queries** — OSINT lookups use SHA-256 hashes, never raw PII
- **Recovery** — Shamir's Secret Sharing for key recovery across devices

## 🏗️ Architecture Overview

IdentityLens uses an **event-driven microservices architecture** with a **zero-knowledge privacy model**. The system is designed so that the server never has access to raw user data — all PII is encrypted client-side before transmission.

### Key Architectural Principles

| Principle | Implementation |
|---|---|
| **Zero-Knowledge** | Client-side AES-256-GCM encryption; server stores only encrypted blobs |
| **Event-Driven** | RabbitMQ/Kafka message bus decouples OSINT collection from NLP processing |
| **Durable Workflows** | Temporal.io orchestrates multi-week deletion flows with retry logic |
| **Data Minimization** | No raw PII stored on servers; results encrypted per-user |
| **Horizontal Scaling** | Stateless microservices behind API gateway; containerized via Docker/K8s |

## 🔧 Core Modules

### 1. Identity Seeder
```
Input: email, legal name, phone, usernames
   │
   ├── SHA-256 hash all PII for breach lookups
   ├── HMAC tokens for platform-specific queries
   └── AES-256-GCM encrypt raw seeds (client-side only)
```

### 2. OSINT Discovery Engine
```
Hashed Seeds ──▶ Parallel Scanners
                  ├── Sherlock / Maigret (username enum, 3,000+ sites)
                  ├── HIBP / DeHashed (breach databases)
                  ├── Holehe (email registrations)
                  ├── PhoneInfoga (phone exposure)
                  ├── SpiderFoot (automated recon)
                  └── Playwright / Scrapy (dynamic scraping)
```

### 3. Perception AI Pipeline
```
Raw Mentions ──▶ spaCy Preprocessing
                  ├── GLiNER Zero-Shot NER
                  ├── Entity Disambiguation (context-window)
                  ├── RoBERTa Aspect-Based Sentiment
                  ├── HateBERT Toxicity Scoring
                  └── Composite Risk Score Calculator
                       Formula: 0.4×breach + 0.3×broker + 0.2×sentiment + 0.1×shadow
```

### 4. Remediation Engine
```
Flagged Results ──▶ Deletion Orchestrator (Temporal.io)
                     ├── [A] Headless Opt-Out (Playwright + CAPTCHA solver)
                     ├── [B] DSAR Email Generator (GDPR/CCPA/DPDP templates)
                     ├── [C] OAuth API Deletion (DELETE /posts/{id})
                     └── [D] Search Deindexing (Google/Bing APIs)
```

### 5. Continuous Re-Monitor
```
Weekly Cron ──▶ Re-scan all seeds
                  ├── Delta comparison (new vs. previous results)
                  ├── If re-listed → auto-retrigger deletion
                  └── If clean → log & update score
```

## 🔐 Security & Privacy

### Zero-Knowledge Architecture

| Layer | Mechanism |
|---|---|
| **Input Encryption** | All PII encrypted with AES-256-GCM in-browser via Web Crypto API |
| **Key Derivation** | Argon2id(password, random_salt) → master key (never transmitted) |
| **Breach Queries** | SHA-256 hashed emails/passwords — raw values never leave client |
| **Server Storage** | Encrypted blobs only; server cannot decrypt without user's key |
| **Key Recovery** | Shamir's Secret Sharing (3-of-5 shares across user devices) |
| **Transport** | TLS 1.3 enforced on all API communications |
| **Secrets** | API keys managed via HashiCorp Vault (not env files in production) |

### Regulatory Compliance

| Framework | Coverage |
|---|---|
| **GDPR** Article 17 | Right to Erasure (EU) |
| **CCPA** §1798.105 | Right to Delete (California) |
| **DPDP Act** §12 | Right to Erasure (India) |
| **LGPD** Article 18 | Right to Deletion (Brazil) |
| **PIPEDA** | Right to Withdraw (Canada) |
| **DELETE Act** (SB 362) | California DROP Portal Integration |

## 🗑️ Remediation Engine

### Supported Deletion Methods

| Method | Targets | Automation Level |
|---|---|---|
| **Headless Browser Opt-Out** | Data brokers (Spokeo, WhitePages, etc.) | Fully automated (Playwright + CAPTCHA) |
| **Direct API Revocation** | OAuth-linked platforms (X, Reddit, LinkedIn) | Fully automated (REST DELETE) |
| **DSAR Email Generator** | Any entity subject to GDPR/CCPA/DPDP | Semi-automated (template + send) |
| **Search Deindexing** | Google, Bing | Automated (Search Console/Webmaster API) |
| **State Registry** | California DROP, EU EDPB | Automated (form filing) |

### Deletion Workflow States

```
  QUEUED → SUBMITTED → IN PROGRESS → AWAITING CONFIRMATION → COMPLETED
                                  └─▶ FAILED (retry 3x) → MANUAL QUEUE
```
